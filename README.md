# MyScript iPad web app

## Deploy to Vercel
1. Upload these files to the root of a GitHub repository (not inside another folder).
2. In Vercel select Add New > Project > Import repository.
3. Framework Preset: Other. Root Directory: ./ . Build Command: leave empty. Output Directory: leave empty.
4. Deploy and open the resulting https:// URL in Safari.

## Quick check
Tap 'Test buttons' at the top. If a success message appears, JavaScript is running. Then draw a character and save it. Samples are saved in browser localStorage for this origin. Avoid private browsing.

Note: exports are images, not individually editable GoodNotes pen strokes. iPad Safari may open a preview/share sheet rather than directly save files.
